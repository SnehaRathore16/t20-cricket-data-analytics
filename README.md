## 📖 Overview

This project demonstrates an end-to-end Data Analytics workflow by collecting, cleaning, transforming, and analyzing T20 Cricket World Cup data.

The project combines **Python**, **Pandas**, **Web Scraping**, **JSON Processing**, and **Power BI** to create an interactive dashboard that identifies the Best Playing XI based on player performance metrics.

---

## 🎯 Business Problem

Build a data-driven Best Playing XI capable of:

- Scoring **180+ runs** on average
- Successfully defending **150+ runs**
- Selecting players based purely on statistical performance
